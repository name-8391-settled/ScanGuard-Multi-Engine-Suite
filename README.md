No. MultiEngine Scanner Suite is designed to complement your primary antivirus solution, not replace it. Think of it as an on-demand second opinion scanner — similar to how security professionals use online multi-scanners to cross-reference detections before making a verdict.

### Are my files uploaded to any external server during a scan?

By default, all scanning is performed entirely on your local machine. No file content is transmitted externally. The only network activity occurs during engine and signature updates, or if you explicitly configure an API-based integration that involves remote submission.

The tool fully supports Windows 10 (version 1903 and later, 64-bit editions) and Windows 11. Older versions of Windows such as Windows 7, Windows 8, and 32-bit systems are not officially supported.

### How often are the detection engines updated?
